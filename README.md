# Hi, I’m Rohit

I build tools that help coding agents remember what they’ve learned and show where their time and tokens go. I also like building things from scratch to see how they work, from language models to interpreters and databases.

## Tools for coding agents

**[secondnature](https://github.com/Rohitp/secondnature)** turns repeated corrections from past coding sessions into lessons. You decide what to keep, and it brings those lessons back when they’re relevant. It also makes past sessions searchable, so you can find out why you made a decision or where you left off.

**[claude-mods](https://github.com/Rohitp/claude-mods)** adds three tools to Claude Code. Context Lens shows what’s filling the context window, Cache Guard tracks when the prompt cache may expire, and Lessons spots repeated tool failures and suggests rules to prevent them.

[![Context Lens and Cache Guard running inside Claude Code](https://raw.githubusercontent.com/Rohitp/claude-mods/main/docs/images/terminal-context-lens.png)](https://github.com/Rohitp/claude-mods#context-lens)

**[mcp-cli-coder](https://github.com/Rohitp/mcp-cli-coder)** lets other tools call Gemini through the Model Context Protocol to analyze individual files or whole directories.
